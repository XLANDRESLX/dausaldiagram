GUÍA RÁPIDA

Cómo usar CausalDiagram Studio

1. Introduce tus datos

Pega una lista de variables y relaciones con flechas. También puedes pegar una tabla con columnas de origen, destino y polaridad.

2. Genera y organiza

Presiona «Generar diagrama». Arrastra los nodos para ajustar su posición o utiliza las distribuciones automáticas.

3. Edita y analiza

Selecciona un nodo o una flecha para cambiar sus propiedades. Los ciclos cerrados se clasifican automáticamente: R (reforzador) o B (compensador).

4. Guarda y exporta

Los cambios se guardan en este navegador. Puedes descargar el proyecto JSON o exportar PNG, SVG y PDF.

El análisis de lenguaje natural es heurístico: revisa siempre las relaciones inferidas antes de generar el modelo.
